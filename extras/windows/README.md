# Extras para Windows

Lanzador de escritorio, indexador de documentos, fuentes de noticias, actualizador y plantillas de configuración y persona.

Consulta la guía completa en [`.github/README.md`](../../.github/README.md).

| Archivo | Qué hace |
|---|---|
| `app/OpenJarvis.vbs` · `app/OpenJarvis.ps1` | Lanzan OpenJarvis como app de escritorio (Edge en modo aplicación). |
| `app/splash.html` | Pantalla de carga mientras arranca el servidor. |
| `instalar-accesos-directos.ps1` | Crea los accesos directos en el escritorio y el menú Inicio. |
| `indexar-documentos.py` | Convierte documentos de Office/PDF a Markdown, tapa secretos y los prepara para `jarvis memory index`. |
| `configurar-noticias.py` | Configura el conector RSS con fuentes de seguridad y Microsoft. |
| `actualizar.ps1` | Actualiza desde el repositorio oficial y vuelve a aplicar esta rama. |
| `plantillas/` | `config.toml` en castellano y plantillas de `SOUL.md`, `USER.md` y `MEMORY.md`. |
